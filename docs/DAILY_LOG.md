## 🗓️ Day 5: 백엔드 공공 API 수집 및 DB 저장 파이프라인 구축

- **작업 일자**: 2026-07-28
- **주요 목표**: H2 DB 연동, JPA Entity 작성 및 공공 API 데이터 수집/저장 파이프라인 수립

### 📝 주요 작업 내용

1. **H2 Database 세팅**: In-Memory DB 연동 및 `/h2-console` 웹 콘솔 활성화.
2. **JPA Entity & Repository 작성**: `Festival` 엔티티 및 `FestivalRepository` 작성.
3. **데이터 수집 로직 구현**: `RestTemplate` & `ObjectMapper`를 활용하여 외부 API 데이터를 DB에 일괄 저장 (`saveAll`).
4. **REST API 연결**: `/api/festivals/save` (수집) 및 `/api/festivals` (조회) 구현.

## 🗓️ Day 6: 백엔드 REST API - 프론트엔드 연동 및 마커 표시

- **작업 일자**: 2026-07-29
- **주요 목표**: 프론트-백엔드 서버 통신 및 DB 데이터 기반 카카오 지도 렌더링

### 📝 주요 작업 내용

1. **CORS 문제 해결**: `@CrossOrigin(origins = "*")` 설정을 통한 교차 출처 리소스 공유 허용.
2. **프론트엔드 API 엔드포인트 전환**: 외부 API 직접 호출에서 내 백엔드 API 주소로 변경.
3. **좌표 필드 동적 바인딩**: 백엔드 DB 구조(`lat`, `lot`)에 맞게 JS 데이터 파싱 로직 개편 및 마커 동적 표시.
